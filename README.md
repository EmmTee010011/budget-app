# My Budget App 💸

A cute and simple personal budgeting app made with HTML, Tailwind CSS, and JavaScript.

## Features

- Create monthly, cutoff/payday, or custom-period budgets
- Add categories with emojis
- Track income, planned expenses, and remaining balance
- Choose a custom theme color
- Save budgets in the browser using localStorage
- Can be installed on Android as a PWA

## Built With

- HTML
- Tailwind CSS
- JavaScript
- localStorage

## Note

This project is still being developed and is made for learning and personal use.
